# Hey all! 👋

I'm Naftali, a full stack software engineer in New York with over 16 years of experience.

I enjoy building things, figuring out how they work, and sharing what I've learned along the way. Lately, a lot of my spare time has gone into building games for the browser and working on open-source projects.

## What I'm working on

- **[Verticopolis](https://github.com/maniator/verticopolis)**: A browser-based homage to the original SimTower. Build a tower, manage elevators and tenants, and work your way up to TOWER. It has Classic and Modern modes, with a simulation engine written in Rust and compiled to WebAssembly. [Play it](https://verticopolis.com/) · [Read more](https://naftali.dev/projects/verticopolis/)
- **[BlipIt Baseball Legends](https://github.com/maniator/blipit-legends)**: A self-playing baseball simulator with a spoken announcer and a Manager Mode where you can make the calls. I originally started building it with my son in 2020. [Play it](https://blipit.net/) · [Read more](https://naftali.dev/projects/blipit-legends/)

## Other open-source work

- **[Docker images: gh and dind-buildx](https://naftali.dev/projects/docker-images/)**: Small, multi-architecture images for CI workflows, including the GitHub CLI and Docker-in-Docker with buildx.
- **[Servable](https://naftali.dev/projects/servable/)**: A dependency-free implementation of Observables, subjects, and operators that I built from scratch. I've also given a couple of meetup talks about building Observables.

I also enjoy sharing what I've learned. You can find talks, writing, and more of my projects over at **[Naftali.dev](https://naftali.dev/)**.
